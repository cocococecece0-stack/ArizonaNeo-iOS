# AGENTS.md

Постоянные правила для работы над проектом `ArizonaNeo-iOS`.

## Платформа и архитектура
- Сохранять совместимость с iOS 15+ и архитектурой ARM64.
- Не добавлять зависимости или код, несовместимые с iOS ARM64.
- Параметры iOS (sysroot, архитектура, deployment target) должны быть воспроизводимы в CI.

## Сохранение кода и истории
- Не удалять существующий код без обоснования в отчёте.
- Сохранять существующую структуру проекта и Git-историю.
- Не выполнять `git push` без явного разрешения пользователя.

## NeoMLoader и MonetLoader
- Целевой загрузчик — NeoMLoader (Android-версия Arizona RP).
- MonetLoader использовать только как архитектурный референс, не как замену NeoMLoader.
- Не переносить Android-библиотеки (ELF/.so) напрямую в iOS-проект.
- Не заявлять поддержку JNI, Android ELF или Android API на iOS без реальной реализации.

## Заглушки и честность реализации
- Не использовать фиктивные заглушки вместо работающих функций.
- Не добавлять фиктивную реализацию Lua runtime.
- Не скрывать ошибки сборки; все ошибки должны быть видны в отчёте.
- Не изменять оригинальные бинарники Arizona.

## Тесты и качество
- После каждого изменения запускать подходящие тесты.
- При отсутствии тестов явно указывать это в отчёте.
- Не переходить к следующему этапу без отчёта о предыдущем.

## Безопасность
- Не публиковать секреты, сертификаты и приватные ключи.
- Не собирать и не подписывать IPA без явного разрешения.
- Не внедрять код в IPA.

## Лицензии
- Проверять лицензии всех сторонних компонентов перед подключением.
- Не скачивать случайные библиотеки и не подключать сомнительные зависимости.

## Отчётность
- Каждый этап завершать подробным отчётом: что проверено, что исправлено, какие команды запускались, что осталось сделать.
